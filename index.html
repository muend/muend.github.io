Flagship Systems

MCP · GeoAI Infrastructure

arcgis-mcp-bridge

An institutional-grade Model Context Protocol framework exposing exactly 100 specialized geoprocessing tools directly to LLM hosts — turning ArcGIS Pro into a programmable backend for AI workflows.

  • Decoupled multi-process architecture: async core and isolated worker subprocess.
  • Strict PathGuard sandbox with prefix validation before any execution.
  • Designed for controlled local ArcGIS Pro automation from LLM hosts.

Spatial DSS · SaaSLIVE

agri-dss

A fully client-side Spatial Decision Support System for the Western Antalya agricultural corridor — 5 districts, 147 neighborhoods — turning agronomic and economic knowledge into a concrete, printable plan per neighborhood.

  • Zero-backend static architecture; vanilla JS against a decoupled data layer.
  • DRY crop / region data contract resolved at runtime.
  • Swiss typographic UI with clean A4 print output.

Simulation · Browser GameLIVE

FOUNDER.EXE

A browser-based startup simulation game modeling the practical stress of founding a company in Türkiye or the USA: taxes, company types, grants, investor expectations, regulation, cash flow, bankruptcy, and exit outcomes.

  • Idea-aware onboarding analyzes sector, market path, and regulatory requirements.
  • Optional live AI assistant via the player's own Gemini, OpenAI, or Anthropic API key.
  • Static web release on itch.io; local save, free / pay-what-you-want access.
