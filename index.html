Experience

work · research · education
Sep 2026

AI Engineer (Contract) · EatBetter

Contract work on an AI-powered nutrition app, run on one rule: measure the model before changing it.

  • Evaluation platform. Built a 923-case benchmark from scratch: 569 human-adjudicated gold labels, a 277-case sealed holdout, 16 deterministic metrics and 742 automated tests in CI. Comparisons use user-clustered bootstrap confidence intervals, and the release gate counts missing evidence as a failure.
  • Model decisions by measurement. Retired a model that cost 7× more after showing no gain (ΔF1 −0.006, 95% CI [−0.023, +0.012]), and shut down a candidate pipeline that lost to the bare model in 4 of 4 comparisons.
  • Assistant safety. On a frozen 400-case scorecard, a fix for users with long memory profiles cut the missed-allergy-context veto rate from 96.4% to 2.1%, the only one of ten candidates to pass the gate. The LLM judge was calibrated on 80 hand-labelled meals (agreement 0.82 against a 0.66 rule baseline).
  • Production data quality. In a live PostgreSQL catalogue of about 387k rows, soft-deleted 88,970 and unpublished 90,735. Every write ran as a ROLLBACK rehearsal against a predicted row count before a human-approved COMMIT, and a rule plus LLM write gate closed the source.

Python · TypeScript / Node.js · PostgreSQL · Azure OpenAI
