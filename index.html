Practice

What guides the work

Evidence before claims

Benchmarks and agent systems should state what was measured, what was not measured, and where the evidence stops.

Spatial validity

CRS, units, spatial leakage, support, uncertainty, and reproducible splits are part of the method, not cleanup steps.

Controlled automation

Tool access should be explicit, local runtimes should stay isolated, and mutations should be bounded and auditable.

Usable research software

Research code is more valuable when it has clear interfaces, deterministic checks, documentation, and practical outputs.
