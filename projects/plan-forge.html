Plan Forge

A planning report workflow that keeps source documents local and requires expert approval before draft content becomes a report.

Workflow

Source documents become approved reports

Plan Forge is a Windows desktop application for planning-report preparation. A local DOCX document is parsed into text, tables and images; the user maps those layers into a versioned template and an expert freezes the approved draft before DOCX/PDF output is produced.

The product combines a React interface with a Python/FastAPI backend and local SQLite storage. The v0.2.2 Windows build includes publisher metadata, PyInstaller packaging and an auditable document-export workflow.

Controls

AI drafts stay behind an approval boundary

  • Source documents and the database stay local.
  • Gemini drafting receives verified, anonymized fields; images require separate explicit approval.
  • Unsupported numbers, dates, parcel references and regulatory citations are blocked before output.
  • Report mappings are versioned and exports retain an audit record; credentials use Windows Credential Manager.
Evidence boundary

Private repository. This describes implemented software and a Windows build, not a claim of municipal deployment, paying customers or adoption. A walkthrough can be discussed directly.
