Method

Methodological checks before a geographic claim

Eighteen independently installable skills cover the geospatial lifecycle: data acquisition, remote sensing, spatial statistics, ML validation, PostGIS, cartography and guarded ArcGIS automation. They require coordinate systems, units, validity, comparability, leakage controls, provenance and uncertainty to be made explicit.

v0.4.1 packages those skills for Codex, Claude Code, GitHub Copilot and compatible Agent Skills runtimes. Runtime archives stay separate from evaluation cases and private development material.

Evaluation

Routing and behavior are separate evidence

The routing run records 99.17% precision, 96.77% recall and 96.41% full-route accuracy on Claude Code 2.1.214 with claude-sonnet-5. The later behavior experiment uses 92 clean matched pairs and a model judge: criterion coverage changes from 28.1% to 48.0%, while critical spatial failures change from 14.1% to 4.3%.

The behavior project gate remains unmet: all-criteria success is 19.6% against an 85% requirement, and critical failures are 4.3% against a below-2% requirement. A 47-case blinded human-review sample is prepared but not adjudicated. The published behavior results are model-judged, uncalibrated and not human-verified.

Evidence boundary

The routing and behavior packages use different runtime versions and suite hashes. Neither supports a universal model-independent quality claim. Package and source links above expose the evidence and its limitations.
