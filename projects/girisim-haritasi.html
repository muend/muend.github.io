Product

Heterogeneous records, one traceable profile

Girişim Haritası is the first working product of a broader company-data platform. It collects public records from defined methods, resolves duplicate entities and preserves field-level source and date information rather than presenting an unsourced directory.

The 2 November build contains 3,257 company profiles assembled from 4,306 source records and 23 collection methods. Profile counts measure catalogue coverage; they are not customer or active-user numbers.

Engineering

An operated data pipeline, not a one-off scrape

  • Collection contracts, entity resolution, incremental enrichment and dated feed records.
  • PostgreSQL schema and loading, Cloudflare Workers APIs and D1-backed keys and usage quotas.
  • OpenAPI documentation, search/filtering and sourced profile views.
  • Scheduled feeds and checks before publication; prototype modules are distinguished from future product goals.
Evidence boundary

The source repository is private; the public platform and API documentation are linked. Data coverage is a dated snapshot, not a claim of complete ecosystem coverage.
