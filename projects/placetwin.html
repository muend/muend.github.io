Open Mendirek
Product

Source records become a working studio

Mendirek is the current studio product; PlaceTwin is the portfolio project name. It combines a 3D Ayvalık twin, a team workspace and a gated website. The current dataset covers 1,712 structures and 669 cadastral parcels over two study areas totaling 43.6 hectares.

It integrates the surveyed base map, cadastral geometry and field records instead of treating all heights as equally certain. The current height classes contain 475 field-backed records, 915 survey/title-deed records and 322 estimates with stated ranges. Structures include ancillary shelters.

Engineering

Analysis and collaboration share the same data

  • Sunlight and sea-view analysis, infrastructure screening and scenario layers in a three.js scene.
  • TUREF/TM27 (EPSG:5254) export, geometry checks and source-aware building/parcel records.
  • Shared tasks, field notes and a Claude assistant that calls tools over the twin and planning records.
  • JavaScript/Node builds, Cloudflare Pages and D1 persistence. The 1 November record reports 790 twin tests; panel and site checks are tracked separately.
Evidence boundary

The repository remains private. The live studio site at studyomsahane.online requires authorized membership. Risk layers are screening tools, not official hazard or planning documents. The case-study inventory was verified on 2 November 2026; code changes and deployed site versions can differ.
